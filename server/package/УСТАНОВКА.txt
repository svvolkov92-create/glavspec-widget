КАБИНЕТ ЗАКАЗЧИКА — СЕРВЕР
==========================

Что это. Небольшая программа-сайт. «Пульт главспеца» отправляет на неё то, что можно
показать заказчику (стадия, план, запросы, разделы — без денег, подрядчиков и фамилий
исполнителей). Заказчик входит по логину и паролю с компьютера или телефона, видит свои
проекты, отвечает на запросы, просит перезвонить или задаёт горящий вопрос. Сообщения
приходят ГИПу в «Пульт» (уведомление Windows + панель «От заказчиков» на сводке).

Сервер один на всю команду. Ставится ОДИН раз: на офисный компьютер или на арендованный
сервер в интернете. Сторонних библиотек нет — нужен только Node.js 20 или новее.

Данные сервера — один файл data\cabinet.json (проекты, учётные записи заказчиков,
сообщения). Пароли хранятся только в виде хеша (scrypt). Копируйте этот файл в резерв.


ВАРИАНТ 1. ОФИСНЫЙ КОМПЬЮТЕР (заказчик заходит из офиса или через проброс порта)
-------------------------------------------------------------------------------

1. Распакуйте архив, например в C:\Кабинет (не на рабочий стол).
2. Двойной щелчок по «Запустить.cmd». Если Node.js не установлен, сервер запустится
   на среде установленного «Пульта главспеца». В окне появятся:
     адрес   — http://0.0.0.0:8080 (0.0.0.0 значит «на всех сетевых адресах»)
     ключ команды — длинная строка.
   Окно не закрывайте: закрыли — сервер остановился.
3. В «Пульте»: Вид → Настройки → Кабинет заказчика → Подключить. Адрес — IP этого
   компьютера в сети, например http://192.168.1.10:8080 (узнать: ipconfig, строка
   «IPv4-адрес»). Ключ — из окна сервера. На этом компьютере можно http://localhost:8080.
4. Чтобы сервер работал без открытого окна и сам стартовал с компьютером:
   установите Node.js 20+ (https://nodejs.org, версия LTS), затем правой кнопкой по
   «Автозапуск (от администратора).cmd» → «Запуск от имени администратора».
   Скрипт создаст задание в Планировщике (от имени SYSTEM) и откроет порт в брандмауэре.
   Убрать: schtasks /Delete /TN "Кабинет заказчика" /F

Доступ заказчика из интернета с офисного компьютера: нужен «белый» IP или проброс порта
на роутере и обязательно https (см. «Шифрование» ниже). Без https пароли заказчиков идут
по сети открытым текстом — «Пульт» об этом предупредит. Если https в офисе настроить
некому — лучше вариант 2.


ВАРИАНТ 2. АРЕНДОВАННЫЙ СЕРВЕР (VPS) С ДОМЕНОМ — РЕКОМЕНДУЕТСЯ ДЛЯ ЗАКАЗЧИКОВ
---------------------------------------------------------------------------

Подойдёт самый дешёвый VPS с Ubuntu 22.04/24.04 и домен (или поддомен), например
cabinet.example.ru, у которого запись A указывает на IP сервера.

  # Node.js 20+ и Caddy (сам получает и продлевает сертификат https)
  sudo apt update && sudo apt install -y nodejs caddy
  node -v                          # должно быть v20 или выше; иначе ставьте с nodejs.org

  # программа
  sudo mkdir -p /opt/cabinet/data
  # скопируйте содержимое архива в /opt/cabinet (scp, WinSCP)
  sudo useradd --system --home /opt/cabinet cabinet
  sudo chown -R cabinet /opt/cabinet

  # служба
  sudo cp /opt/cabinet/cabinet.service /etc/systemd/system/
  sudo systemctl daemon-reload && sudo systemctl enable --now cabinet
  journalctl -u cabinet -n 20      # здесь ключ команды

  # https: впишите свой домен в Caddyfile.example
  sudo cp /opt/cabinet/Caddyfile.example /etc/caddy/Caddyfile
  sudo systemctl reload caddy

В «Пульте» адрес — https://cabinet.example.ru, ключ — из журнала службы.
Служба слушает только 127.0.0.1:8080, снаружи доступен лишь Caddy (порты 80 и 443).


НАСТРОЙКИ (config.json рядом с cabinet-server.js — по образцу config.example.json)
-------------------------------------------------------------------------------
  port        порт (по умолчанию 8080)
  host        0.0.0.0 — все адреса; 127.0.0.1 — только для прокси на этой же машине
  title       заголовок страницы входа
  font        golos или montserrat
  timeZone    часовой пояс для «осталось N дней», например Europe/Moscow,
              Asia/Vladivostok. По умолчанию — пояс компьютера (на VPS это часто UTC)
  trustProxy  true, если сервер стоит за Caddy/nginx (для https-куки и учёта попыток входа)
  sessionDays сколько дней заказчик остаётся залогиненным (по умолчанию 30)
  tls         { "cert": "путь.pem", "key": "путь.key" } — https без прокси
Те же параметры можно задать переменными окружения CABINET_PORT, CABINET_HOST,
CABINET_DATA, CABINET_TZ, CABINET_TRUST_PROXY.


ШИФРОВАНИЕ И БЕЗОПАСНОСТЬ
-------------------------
- Для доступа из интернета — только https (Caddy делает это сам, см. вариант 2).
- Ключ команды даёт полный доступ к кабинету: публикация проектов, учётные записи.
  Храните его как пароль. В «Пульте» он хранится зашифрованным средствами Windows.
  Если ключ утёк: остановите сервер и выполните
      node cabinet-server.js --new-key
  затем введите новый ключ во всех «Пультах».
- Заказчик видит только проекты, к которым ему открыт доступ, и только после публикации.
- 8 неудачных попыток входа под одним логином (или 20 с одного адреса) — пауза 15 минут.
- «Новый пароль» в «Пульте» сразу завершает все сеансы заказчика.


КАК ЭТО РАБОТАЕТ В «ПУЛЬТЕ»
---------------------------
Проект → вкладка «Для заказчика» → блок «Кабинет заказчика»:
  «Сохранить и опубликовать» — проект появляется в кабинете. Дальше после каждого
     сохранения проекта страница обновляется сама в течение 2 минут.
  «Открыть доступ» — имя и логин; пароль покажется один раз, кнопка «Скопировать для
     заказчика» готовит текст с адресом, логином и паролем.
  «Новый пароль», «Закрыть вход», «Убрать из проекта» — для каждого заказчика.
  Сообщения от заказчика: ответ на запрос можно одной кнопкой отметить «получено».
Каждые 2 минуты «Пульт» забирает новые сообщения; горящий вопрос — уведомлением Windows.
Опубликованная страница — копия: если «Пульт» выключен, заказчик видит последнюю версию,
а сообщения ждут на сервере.
