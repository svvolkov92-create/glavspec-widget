# Сервер Пульта — установка на VPS

Общая база команды «Тандема»: Пульты на компьютерах, веб-версия в браузере и на телефоне, кабинет заказчика — всё работает с одними данными. Каждый входит своим логином и получает только то, что ему положено: деньги и контакты заказчика — только ГИП (или тот, кому ГИП открыл).

## 1. Арендовать VPS

У любого российского хостинга (Timeweb Cloud, Selectel, REG.RU, Beget и т. п.):

- система **Ubuntu 24.04** (подойдут Ubuntu 22.04 и Debian 12);
- 1 процессор, 1–2 ГБ памяти, диск от 15 ГБ — для команды в десятки человек хватит;
- при создании задайте пароль root (или добавьте свой SSH-ключ);
- запишите **IP-адрес** сервера.

## 2. Положить установщик на сервер и запустить

Файл `install-pult-server.sh` — из сборки на GitHub (артефакт **PultServer**). На компьютере с Windows откройте PowerShell в папке с файлом:

```powershell
scp install-pult-server.sh root@IP-СЕРВЕРА:
ssh root@IP-СЕРВЕРА "bash install-pult-server.sh"
```

(вместо `IP-СЕРВЕРА` — адрес из шага 1; при первом подключении ответьте `yes` и введите пароль root.)

Установка идёт несколько минут и в конце пишет:

- **адрес для Пульта** — вида `pult.1-2-3-4.sslip.io` (сделан из IP, шифрование настраивается само);
- **веб-версию** для телефона — тот же адрес с `/app/`;
- **адрес кабинета заказчика** — `kabinet.1-2-3-4.sslip.io`;
- **код установки** — нужен один раз, для переноса базы.

Те же сведения сохраняются на сервере в `/root/pult-server.txt`.

Свой домен потом: в DNS направьте `pult.ваш-домен.ru` и `kabinet.ваш-домен.ru` на IP сервера и запустите установщик ещё раз с `--domain ваш-домен.ru`.

## 3. Перенести базу (ГИП, один раз)

В Пульте ГИПа: **меню → «Сервер Пульта…» → «Перенести мою базу на сервер»** — адрес, код установки, придумайте логин и пароль. Пульт отправит базу, журнал и все приложенные файлы и перезапустится уже с общей базой. Файл на компьютере ГИПа остаётся как был — копией.

## 4. Подключить людей

ГИП: **«Сервер Пульта…»** → в таблице «Вход в Пульт» → **«Пригласить»** у человека. Появится код и готовый текст приглашения — отправьте его человеку (мессенджер, почта). Человек:

- **в Пульте на компьютере:** меню → «Сервер Пульта…» → «Подключиться» → адрес, код, придумать логин и пароль;
- **на телефоне:** открыть ссылку из приглашения → придумать логин и пароль → в меню браузера «Добавить на главный экран».

Там же ГИП сбрасывает пароль, отключает вход (уволился — одна кнопка, все его сеансы закрываются) и видит, с каких устройств входили.

## Права

- **ГИП** — всё.
- **Главспец** — свои проекты и люди; деньги (бюджеты, договор, оплаты) — только если ГИП отметил «видит бюджет»; заказчики и их контакты — только если отмечено «видит заказчиков и их контакты» (карточка человека в «Людях»).
- **Специалист** — свои карточки и проекты, где он участник.

Проверяет сервер: запрещённое просто не отправляется на компьютер или телефон.

## Без связи

Пульт работает дальше на своей копии; изменения копятся («Нет связи · ждут отправки N») и уходят сами, когда связь вернётся. Если двое поправили одно поле — Пульт покажет оба значения и спросит, какое оставить.

## Копии

- Сервер каждую ночь сохраняет базу в `/var/lib/pult/backups` (30 дней).
- Вторая копия — у ГИПа: в Пульте «Автокопия в папку…» (флешка, облачная папка) — Пульт сам скачивает базу с сервера раз в 12 часов. Или «Сохранить резервную копию…» вручную.

## Обновление

Новый `install-pult-server.sh` — тем же способом (шаг 2). Данные и настройки остаются.

## Если что-то не так

```bash
systemctl status pult-server      # работает ли
journalctl -u pult-server -n 100  # журнал
systemctl restart pult-server     # перезапуск
```

HTTPS не открывается сразу — сертификату нужна минута; проверьте, что у хостинга открыты порты 80 и 443.
