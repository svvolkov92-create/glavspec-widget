# Интерфейс Пульта по частям

`src/renderer/app.js` собирается из этих файлов: `node tools/build-app.js`.
Руками `app.js` не правим — тест `test/app-parts.test.js` и `prepare-ui.js` остановят сборку, если он разойдётся с частями.

Все части работают в одной области видимости (как один файл): функция из одной части видна в любой другой.
Порядок номеров важен только для того, что выполняется при загрузке (`const x = …`, `let`, `document.addEventListener`):
такое ставим не раньше того, от чего оно зависит. Функции (`function name()`) можно переносить между частями свободно.

Кнопки и ссылки: у элемента `data-act="имя"`, а в конце части, к которой он относится, — обработчик:

```js
onAct({
  'имя': ({ e, el, id, act }) => { … },
});
```

`38-events.js` на щелчок находит обработчик по имени. Одно имя в двух частях — ошибка при запуске.
