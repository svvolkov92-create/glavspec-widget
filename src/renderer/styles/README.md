# Стили окна по частям

Собираются в `src/renderer/styles.css` командой `node tools/build-app.js` (вместе с app.js) — правьте части, а не styles.css.
Части идут слоями в порядке каскада: более поздние правила перекрывают ранние, поэтому части нельзя переставлять.

| Часть | Что внутри |
|---|---|
| 00-base | Каркас окна: шрифты, стекло, заголовок, панели и таблицы, отметки разделов, фильтры, шторка, меню отчётов |
| 10-cards-gantt-kanban | Карточки с историей и оплатами, корзина, импорт, Гант, Канбан, поиск, журнал (1.3–1.6) |
| 20-roles-nav-drawer | Роли, дерево команды, положение меню, сворачивание, входящие, шторка, готовность, упрощения (1.7–2.6) |
| 30-header-people | Новый заголовок, штамп карточки, подсказки, люди, отпуска, компактный виджет, тема «Графит» (3.0) |
| 31-customer-project | «Тандем», данные заказчика, кабинет, генератор состава, страница проекта (3.1–3.4) |
| 35-assign-messenger | Задания, чат проекта, доска заданий, массовые действия, мессенджер (3.5–3.8) |
| 40-animations | Анимации; файлы к запросу заказчика |
| 41-windows | Закладки и отдельные окна (4.0) |
| 42-v41 | Гант и Канбан 4.1, фокус, плотность, контраст, «Кто делает», этапы, оргструктура, «Мой день», проверка, портфель, файлы, ИРД, письма, аналитика (4.1–4.1.1) |
| 50-v44-on | Подсказки при создании, Mica, клавиши, свои картинки, «Для заказчика», сервер, контрагенты, договор, меню, ИРД, РВИ, экспертиза, задания, паспорт, настройки, люди (4.4 и дальше) |
